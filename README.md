# Contagem Regressiva em C

Programa simples desenvolvido em linguagem C que realiza uma contagem regressiva a partir de um número informado pelo usuário.

## Como funciona

O programa solicita um número inteiro ao usuário e inicia uma contagem regressiva até `1`.

Após finalizar a contagem, o programa exibe a mensagem **"Lançamento"**.
